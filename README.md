# Books

A place to gather what books leave behind, then see it whole — as interactive concept maps.

- **[Man's Search for Meaning](mans-search-for-meaning/knowledge-graph.html)** — Viktor E. Frankl's ten themes: decisions, meaning, tragic optimism, love and more.
- **[The Wisdom Bridge](the-wisdom-bridge/knowledge-graph.html)** — Daaji Kamlesh D. Patel's nine principles for raising children.
- **[Algorithms & Python](python-pdsa/knowledge-graph.html)** — an evolving notebook of data structures, algorithms and core Python.
- **[Master Concept Map](knowledge-graphs/index.html)** — all three books together in one map, with the cross-book connections between them.

Each map is a single self-contained HTML page built around the same engine: a radial mind map with a hub at the centre, click-to-expand branches, dotted arrows for the associations a book draws between its own ideas, search, keyboard navigation, and image export. Open any of the links above directly in a browser.
