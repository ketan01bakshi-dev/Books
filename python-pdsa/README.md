# Algorithms & Python — Concept Map

An interactive, mind-map-style concept map for the evolving *Algorithms & Python* knowledge notebook — Data Structures, Algorithms and Core Python — built as a single self-contained `knowledge-graph.html` page, using the same engine and interaction model as [Man's Search for Meaning's concept map](../mans-search-for-meaning/knowledge-graph.html).

Eight domains radiate from the notebook's title — Number Theory & GCD, Core Types & Language Foundations, Inductive Definitions & Recursion, Divide & Conquer Sorting, Exceptions/File I/O & Formatting, Backtracking & Priority Queues, User-Defined Types & Search Trees, and Dynamic Programming & Optimization — each opening into its topics, and each filled topic opening further into its own concepts (Euclid's algorithm, aliasing vs. copying, binary search's O(1)-index requirement, Big-O and the Python step budget, selection/insertion/merge sort, and more). Dotted arrows trace the relations the notebook draws between concepts across topics — doubt-like dependencies such as "requires", "achieves", "faster than", and "bounded by".

Open `knowledge-graph.html` in a browser: drag to pan, scroll to zoom, click any topic to expand or collapse it, or use the theme picker to jump straight to a domain.

`app.js` / `course.js` / `index.html` / `styles.css` are a separate, earlier living map of the same notebook; `learnings.md` is the running notebook of interview-ready notes the concept map draws on; `knowledge-graph.json` is the original graph-database export the concept map's data was built from.
